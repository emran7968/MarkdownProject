# Contribution Guidelines

Thank you for your interest in contributing to this project!

## Code Style

- Write clean and readable code.
- Use clear and descriptive names for variables and functions.
- Keep the code organized and properly formatted.
- Add comments when necessary to explain complex parts.

## Pull Requests

- Create a separate branch for each new feature or fix.
- Write clear commit messages describing your changes.
- Provide a clear description of the changes in your pull request.
- Make sure your changes work correctly before submitting.

## Reporting Issues

- Check existing issues before creating a new one.
- Provide a clear and descriptive title.
- Explain the problem and include steps to reproduce it.
- Include screenshots or error messages when relevant.
